# Pedidos Backend Aula 8

- UML (Unified Modeling Language)
- DC (Diagrama de Classes)

Back-end com duas coleções mockup JSON clientes e pedidos, CRUD, para aprender MVC e UML diagrama de Classes.

## Tecnologias usadas: 
- Node.js
- VsCode (Thunder Client)
- JavaScript
- MVC

## Passos para testar: 
- Clone este repositório e abra com VsCode
- Instale as dependências e execute com os seguintes comandos:
* npm init -y
* npm i express
